# CUSTOMROM TAYTECH

Projeto de diagnóstico, otimização e personalização de uma multimídia TayTech Android.

## Fase atual

**ADB primeiro.** O objetivo imediato é medir a causa da lentidão e testar otimizações reversíveis antes de considerar ROM, root, bootloader ou flash.

## Regra de entrada

Leia [`START_HERE.md`](START_HERE.md) antes de qualquer trabalho técnico.

## Princípios

- medir antes de alterar;
- preservar integrações automotivas;
- separar Android, boot/AVB, MCU e CAN;
- rollback obrigatório para mudanças reversíveis;
- GitHub como verdade técnica, Notion como memória operacional e evidência ADB como prova física;
- Codex Engineering Guardrails obrigatório: plugin primeiro, skill direta como fallback.
