# Comece aqui — CUSTOMROM TAYTECH

Este repositório é a memória técnica do projeto de otimização e personalização da multimídia TayTech. O nome humano do projeto é **CUSTOMROM TAYTECH**; o repositório oficial permanece `vitoohugo333/COMSTUMROM`.

Antes de qualquer diagnóstico, comando ADB, alteração, APK modificado ou trabalho de ROM, leia na branch realmente afetada, nesta ordem:

1. bloco do Notion citado pelo proprietário, quando houver;
2. `AGENTS.md`;
3. `SKILLS.md`;
4. `TESTING_RULES.md`;
5. `ADB_RULES.md` para qualquer interação com o Android/ADB;
6. `ROM_SAFETY_RULES.md` para root, bootloader, partições, AVB, firmware, MCU, CAN ou flash;
7. `LEARNING_RULES.md` quando houver defeito, quase falha ou descoberta reutilizável;
8. `PROJECT_STATE.md`;
9. fontes vivas atuais: GitHub, evidência ADB fresca, logs, dumps e estado físico do aparelho.

O Notion organiza missão, blocos, decisões e aprendizados. O GitHub prova o estado técnico do projeto. A evidência ADB e a validação física provam o estado real da multimídia.

O proprietário não deve precisar memorizar SHAs, arquivos de governança, códigos internos ou comandos técnicos para retomar um bloco já documentado.
